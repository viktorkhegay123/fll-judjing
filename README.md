# FLL Judging — электронные судейские сессии

## Деплой на Vercel
1. Залейте папку в репозиторий GitHub.
2. vercel.com → **Add New → Project** → выберите репозиторий → Framework Preset: **Other** → Deploy.
3. В проекте: **Storage → Create Database → Upstash for Redis** (бесплатный план) → Connect to project.
   Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
4. **Settings → Environment Variables**: добавьте
   - `ORG_CODE` — свой код для регистрации организатора;
   - `SECRET` — любая длинная случайная строка (подпись входа).
5. **Deployments → Redeploy** (чтобы переменные подхватились).
6. Проверка: `https://<ваш-проект>.vercel.app/api/health` → `{"ok":true,"store":"redis"}`.

Нагрузка: один судья со страницей на экране ≈ 4 команды Redis каждые 3 секунды (≈ 5 тыс. в час).
6 судей × 6 часов ≈ 170 тыс. команд — укладывается в бесплатный лимит Upstash (500 тыс./мес.).
Свёрнутые вкладки запросов не делают.

## Локальный запуск (запасной вариант, без интернета)
```
node local-server.js
```
Данные хранятся в `data.json`. Судьи в той же Wi-Fi сети открывают адрес из консоли (`http://192.168.x.x:3000`).
Если заданы `KV_REST_API_URL` / `KV_REST_API_TOKEN`, локальный сервер будет работать с той же базой Redis, что и Vercel.

## Как работает
- **Регистрация**: роль (Head Judge / Судья), комната 1–3, имя, логин, пароль. Организатор — галочка + `ORG_CODE`.
- **Head Judge**: закреплённая шапка TIMER | TEAM NAME | TIME. «▶ Вызвать» у команды → «Старт» на каждом этапе
  (2 + 5 + 5 + 5 + 5 + 8 мин, затем 10 мин обсуждение). По окончании этапа — сигнал, таймер ждёт следующий «Старт». Пробел = старт/пауза.
- **Судья**: видит тот же таймер, рубрики сами переключаются на вызванную команду.
- Оценки сохраняются автоматически; при пропаже связи хранятся на устройстве и отправляются позже.

## Подсчёт
- Каждый судья: ИП до 40 баллов (10 строк × 4), ДР до 40.
- ИП итог = (судья 1 + судья 2) ÷ 80 × 25%. ДР — так же.
- Core Values = строки с шестерёнкой обеих рубрик обоих судей (до 20 + 20 у каждого) ÷ 80 × 25%. Шестерёнки остаются и в ИП/ДР.
- Итоговая таблица: Команда | Время | ИП | Дизайн робота | Core Values | ИП + ДР, выгрузка CSV.
